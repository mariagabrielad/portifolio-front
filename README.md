# Checkpoint 6 — Entrelinhas

## Como abrir
1. Extraia a pasta do ZIP.
2. Abra a pasta no VS Code.
3. Abra `index.html` no navegador (ou use a extensão Live Server).
4. Mantenha `index.html`, `style.css` e `script.js` na mesma pasta.

## Importante
As imagens e fontes usam serviços externos e precisam de internet. O formulário é demonstrativo e não envia dados. Confira todos os links, imagens e interações antes de publicar.

A pasta `documentacao` contém a proposta, referências, decisões visuais, prompts sugeridos, registro de correções e análise crítica.
