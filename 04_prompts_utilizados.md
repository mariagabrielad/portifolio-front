# Prompts utilizados

O enunciado pede que o prompt inicial seja registrado exatamente como foi enviado e que os ajustes apareçam na ordem real. Como esta versão do site foi montada a partir de um briefing organizado, os textos abaixo são **prompts sugeridos para registrar o processo**, não transcrições literais de conversas anteriores. Se você usar estes prompts em uma ferramenta de IA, salve o texto e o resultado de cada rodada.

## Prompt inicial
“Crie uma landing page para o Entrelinhas — Clube do Livro. Quero um estilo minimalista, elegante, sofisticado e acolhedor. Use verde `#4A5D4E`, fundo `#F8F9FA`, textos `#2D3142` e botões `#D97450`. Inclua menu, banner principal, apresentação do clube, um segundo banner, carrossel com três livros e sinopses, seção de encontros, formulário de interesse e rodapé. Faça a página funcionar em computador e celular. Use HTML, CSS e JavaScript simples, separados em arquivos.”

## Prompt de ajuste 1 — organização visual
“Revise a hierarquia dos títulos, o espaçamento e a consistência das cores. Mantenha o estilo editorial e evite efeitos decorativos exagerados. Não remova nenhuma seção.”

## Prompt de ajuste 2 — interações
“Confira o menu de celular, as setas do carrossel e o formulário. Cada controle deve ter um comportamento claro. Como não existe servidor, explique na página que o formulário é demonstrativo e não envia dados.”

## Prompt de ajuste 3 — revisão crítica
“Revise a acessibilidade e a responsividade. Confira textos alternativos das imagens, foco visível nos controles, contraste e comportamento em telas estreitas. Liste qualquer limitação que ainda precise ser testada manualmente.”

## Registro real
Se você fizer novas rodadas com IA, copie aqui cada prompt exatamente como foi enviado e registre o que mudou. Não declare que uma ferramenta fez algo se você não executou esse passo.
