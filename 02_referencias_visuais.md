# Referências visuais

Use estas páginas como repertório visual, sem copiar uma composição inteira. Abra cada link, capture a tela e salve a imagem nesta pasta com o nome `referencia-01.png`, `referencia-02.png` etc. Para cada captura, anote o detalhe específico que chamou sua atenção.

1. **The Secret Book Club** — atmosfera literária, identidade de clube e tipografia editorial. https://divega.net/portfolio/the-secret-book-club
2. **Narrative Nebula** — organização de conteúdo e chamadas para ação. https://divega.net/portfolio/narrative-nebula
3. **Dribbble: Bookstore Landing Page** — repertório de banners, cartões e layouts de livraria. https://dribbble.com/search/bookstore-landing-page
4. **Minimal Editorial Book Landing Page** — hierarquia tipográfica e composição minimalista. https://runable.com/templates/minimal-lavender-editorial-book-landing-page-b51be411-bfee-43ba-9ab5-86779dd5c27d
5. **Payly Bookstore Template** — apresentação de livros e uso de tons naturais. https://payly.org/templates/bookstore

## Como analisar cada referência
- O que chamou atenção?
- Qual elemento visual poderia inspirar o projeto?
- Em qual seção da landing page esse elemento seria útil?
- O que foi adaptado para manter uma identidade própria?

**Observação:** confirme que as páginas continuam acessíveis e registre apenas o que você realmente observou nelas. As referências são pontos de partida para pesquisa, não evidência de que o site final foi copiado delas.
